# Sensors

Here are the Arduino scripts. "heart_data.ino" is a script kindly offered by Pelaz from his CMLS project.

The board connections are as it follows:
1. Red cable for each sensor -> 5V supply
2. Black cable for each sensor -> GND
3. Green cable for each sensor -> Analog INPUTS

Inputs:
1. Heart rate -> A1
2. X axis -> A3
3. Y axis -> A4
4. Z axis -> A5
