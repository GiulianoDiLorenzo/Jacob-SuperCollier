# JUCE

The "Source" folder contains the 4 C++ files to use in the .jucer file. Take care to use the "Plugin - basic" template and add both juce_dsp and juce_osc modules.

The standalone file "Effects.exe" allows you to run the plugin directly.

The plugin file "Effects.vst3" allows you to run it inside the AudioPluginHost utility.
